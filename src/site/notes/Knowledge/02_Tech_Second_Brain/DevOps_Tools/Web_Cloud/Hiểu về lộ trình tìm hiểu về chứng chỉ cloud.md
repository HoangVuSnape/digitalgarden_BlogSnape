# Note
 2. AWS Certified Generative AI Developer – Professional - Chứng chỉ Coming Soon của AWS, Beta registration opens November 18, 2025.
![✅](https://static.xx.fbcdn.net/images/emoji.php/v9/t33/1/16/2705.png)Dành cho ai?
- Business Analysts, Product Managers muốn tích hợp nhanh các Foundation model bên khác vào ứng dụng
- Developers/Engineers thích Generative AI, sử dụng các mô hình có sẵn
- CEO/CTO muốn đưa nhanh sản phẩm ra thị trường
 ![✅](https://static.xx.fbcdn.net/images/emoji.php/v9/t33/1/16/2705.png) Scope kiến thức:
- Dev biết và có khả năng tích hợp các Foundation Model trên thị trường vào web/app
- Xây dựng các giải pháp RAG, vector database, fine-tuning cơ bản các Foundation models (using foundation models, RAG architectures, and vector databases)
- Biết prompt engineering cho Bedrock để gen video, hình ảnh, văn bản.
- Hiểu về cách điều chỉnh temperature, topK, topP để tạo sinh nội dung
- Bedrock Agent, Bedrock Prompt Management, Bedrock Knowledge, Bedrock Guardrails
 ![🎓](https://static.xx.fbcdn.net/images/emoji.php/v9/t25/1/16/1f393.png) 3. AWS Certified Machine Learning - Associate - "Sweet spot" cho ML Engineer
![✅](https://static.xx.fbcdn.net/images/emoji.php/v9/t33/1/16/2705.png)Dành cho ai?
- Data Analysts muốn chuyển sang ML Engineer
- Developers có kinh thức programming, muốn làm ML
- ML Engineers fresher/junior (0-2 năm kinh nghiệm)
![✅](https://static.xx.fbcdn.net/images/emoji.php/v9/t33/1/16/2705.png)Scope kiến thức:
- Data ingestion từ nhiều nguồn (S3, Kinesis, Glue)
- Data transformation, cleaning, feature engineering
- Data validation và quality checks
- Handling missing data, outliers, imbalanced datasets
- Chọn algorithms phù hợp (Linear Regression, Decision Trees, XGBoost, Neural Networks)
- Training models với SageMaker
- Deploy models (real-time, batch, edge)
- SageMaker endpoints, auto-scaling
- A/B testing models...
